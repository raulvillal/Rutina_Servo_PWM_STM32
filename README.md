# Rutina_Servo_PWM_STM32
Rutina creada para una serie de servomotores, a partir de los módulos PWM y Timer de la STM32.
Para ejecutar correctamente el proyecto final con el código en C. Se deben seguir los pasos indicados en la página del arcoslab: https://wiki.arcoslab.org/teaching/ie0624/actividad2 para ejecutar el timerblink.c, luego de seguir los pasos, se debe cambiar el código del timerblink.c por el código proporcionado en estos archivos adjuntos, para flashear correctamente la STM32.
